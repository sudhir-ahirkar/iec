# Global Route Company Website

India-based import & export trading company website, built on the Logistica HTML template structure.

## Pages
- Home, About Us, Exports, Imports, Products, Services, Markets, Contact, Quote

## Deploy
Static site — push to GitHub and connect to Netlify (publish directory: site root).

Contact forms use **Netlify Forms** (`data-netlify="true"`). After the first deploy, enable form notifications in the Netlify dashboard.

## Local preview
```bash
python3 -m http.server 8080
```
Then open http://localhost:8080
