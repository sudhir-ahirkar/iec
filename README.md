# Global Route Company Website

India-based import & export trading company website, built on the Logistica HTML template structure.

## Pages
- Home, About Us, Exports, Imports, Products, Services, Markets, Contact, Quote, Thank You

## Deploy
Static site — push to GitHub and connect to Netlify (publish directory: site root).

Contact forms use **Netlify Forms** (`data-netlify="true"`). After deploy, set email notifications in the Netlify dashboard (this is not shown on the public website).
